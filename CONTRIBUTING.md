# Contributing

Issues and pull requests for the SDK, examples, docs and embeds are welcome. Keep the SDK dependency-free and runtime-agnostic (plain `fetch`). Match the API as it is, not as you wish it were: if an endpoint is missing something, open an issue and we will change the service first, then the SDK.

Bugs in a report itself (a wrong finding, a stale figure) are not SDK issues: report them at https://agentsi.site/transparency, which explains the correction process.
